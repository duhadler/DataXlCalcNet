### Welcome to DataXlCalcNet!

This repository contains sample data and short program examples to demonstrate the use of the [XlCalcNet](https://duhadler.github.io/XlCalcNet/) library.

XlCalcNet references the datasets contained in DataXlCalcNet which should be installed before XlCalcNet.

The manual is the same as for XlCalcNet. The part which is specific for DataXlCalcNet starts [here](https://duhadler.github.io/XlCalcNetDocsOnline/B01_GeneralUsage/C07_ContextsXlCalcNet2.html).

The manual can be downloaded in PDF format from https://github.com/duhadler/DocsXlCalcNet/raw/master/pdf/xlcalcnet.pdf.
