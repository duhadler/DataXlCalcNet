### DataXlCalcNet

This repository contains sample data and short program examples to demonstrate the use of the [XlCalcNet](https://github.com/duhadler/XlCalcNet) library.

The manual is the same as for XlCalcNet and is available online in HTML format: [XlCalcNet.html](https://duhadler.github.io/XlCalcNetDocsHTML/). 



When XlCalcNet is installed from [PyPI](https://pypi.org/project/xlcalcnet/), a copy of these datasets is installed with it.
