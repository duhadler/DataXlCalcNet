### DataXlCalcNet

This repository contains sample data and short program examples to demonstrate the use of the [XlCalcNet](https://duhadler.github.io/XlCalcNet/) library.

The manual is the same as for XlCalcNet and is available online in HTML format: [XlCalcNet.html](https://duhadler.github.io/XlCalcNetDocsOnline/). The part which is specific for DataXlCalcNet starts [here](https://duhadler.github.io/XlCalcNetDocsOnline/B01_GeneralUsage/C07_ContextsXlCalcNet2.html).


The manual can also be downloaded in PDF format from [XlCalcNet.pdf](https://github.com/duhadler/DocsXlCalcNet/raw/master/pdf/xlcalcnet.pdf).


XlCalcNet references the datasets contained in DataXlCalcNet which should be installed before XlCalcNet.
